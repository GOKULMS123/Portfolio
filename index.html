Position-Based Optimized Link State Routing (PB-OLSR) for VANET

The project develops a Position-Based Optimized Link State Routing (PB-OLSR) protocol for VANETs using NS-3 to improve routing efficiency in highly dynamic vehicular environments. It integrates real-time GPS-based position data with link-state routing to enhance multipoint relay selection, link stability, and route optimization. Simulations in NS-3 evaluate metrics like packet delivery ratio, delay, and throughput, demonstrating improved performance, reduced overhead, and faster route recovery compared to traditional OLSR.
